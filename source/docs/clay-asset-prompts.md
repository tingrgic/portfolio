## Integration

Clay lettering/icons are ordinary local `<img>` elements marked decorative, with equivalent real headings and link labels. DOM typography is locally hosted Caveat, with DM Sans for small utility text. Only animated page snapshots are rasterized into Three.js textures. No API calls, remote fonts, generated background video or permanently rasterized portfolio content are required at runtime.
